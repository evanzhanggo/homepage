# evanzhang.cloud 个人主页

[evanzhang.cloud](https://evanzhang.cloud) 的源码。这是一个单页静态 HTML，作为 Evan 的个人主页。

页面部署在腾讯云服务器的 nginx 网站根目录，前面由 Cloudflare 代理。

## 如何更新

1. 编辑 `index.html`。
2. 上传前先备份网站根目录里的旧文件。
3. 把新的 `index.html` 上传到 nginx 网站根目录。
